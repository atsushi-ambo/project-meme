# プロジェクト・メメ

メメの動画・鳴き声と前後の状況を記録し、観察、仮説、働きかけ、反応を積み重ねて理解を深める、家族用のブラウザアプリ。アプリ名とプロジェクト名は「プロジェクト・メメ」、仮説集は「メメ辞書」です。体調管理も同じアプリで行います。

現在は設計資料のみです。アプリ、Docker環境、DB、AI解析はまだ実装・接続していません。

- [初版の設計](docs/design.md)

## 初版の利用方法

1. iPhoneで動画・写真・鳴き声を撮る。
2. AirDropなどでMacBookへ移す。
3. MacBookのブラウザからファイルを取り込み、日時、状況、前後の動き、コメントを記録する。
4. 意味の仮説を関連づけ、働きかけとメメの反応を追記する。
5. 過去の記録と比較し、メメ辞書を育てる。

添付なしでも記録できます。猫語の翻訳、診断、意図の確定を約束するものではありません。

## 技術と学習

Python・FastAPI・Jinja2・PostgreSQLを採用し、SQLAlchemyでDBにアクセス、Alembicでテーブル構造の変更を管理する予定です。Uvicorn、Psycopg 3、フォーム受信用のpython-multipart、pytest＋HTTPXも使います。DB操作は同期処理で始めます。Docker ComposeでアプリとDBを動かし、PythonやPostgreSQLをMacBookへ直接インストールしない構成にします。MacBookにはDocker実行環境が必要です。

Pythonの入力検証からSQL、保存、画面表示まで説明し、主キー・外部キー・多対多の関連、トランザクション、HTTPとAPIを学べる構成にします。pgvectorによる意味検索は後続の学習段階で検討します。

## 保存と利用範囲

初版はMacBookのlocalhostだけで利用し、ログインで利用者を区別しません。iPhoneから自宅LAN経由で直接利用する機能は、ログインとセッション保護を整えてから追加します。インターネット公開は不要です。MacBookの停止・スリープ中は利用できません。

コードと設計資料をGitで管理し、動画・写真・音声・DB・認証情報はコミットしません。Dockerの永続保存領域へデータを保存し、バックアップは別途用意します。実データを外部AIへ送信しません。

容量上限、バックアップ先と保持期間は未決定です。添付の標準保存期間は60日の予定ですが、期限処理を実装・検証するまでは設定のプレビューとして扱い、その段階は開発途中の試作です。初版の完成には期限処理と失敗回復を含めます。

初版からCSRF対策、入力検証、SQLのパラメータ化、HTMLエスケープ、添付の検証と安全な保存、Host・送信元の検証を組み込みます。観察・辞書・体調とその関連を10テーブルに分け、設計書に各テーブルの理由と制約を記載しています。現時点では対策も未実装です。
