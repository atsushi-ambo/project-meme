# プロジェクト・メメ

メメの動画・鳴き声と前後の状況を記録し、声・行動、その後の様子、予想を積み重ねるローカルアプリ。「メメ辞書」と体調日記を同じ画面から利用できます。Python・API・PostgreSQLの学習を兼ねています。

## 起動

Docker実行環境が必要です。Python・PostgreSQL・依存ライブラリはDocker内で動きます。設定作成とバックアップのスクリプトだけMacBookの標準Pythonで実行します。

```sh
cd ~/personal/app/project-meme
python3 scripts/setup.py
docker compose up -d --build
```

[http://localhost:8000](http://localhost:8000) を開きます。DBの準備とマイグレーションの後にアプリが起動します。

```sh
docker compose stop                  # 停止。データは残る
docker compose up -d                 # 再起動
docker compose logs --tail=50 web    # エラーの確認
```

`.env`は自動生成され、既存の設定は上書きしません。秘密値をGitへ入れないでください。通常の停止に`docker compose down -v`は使いません。`-v`はDBの保存領域も削除します。

## 使い方

1. iPhoneで撮影したファイルをAirDropでMacBookへ移します。ProResはオフ、HEVC撮影を想定しています。
2. ファイルを `~/Movies/project-meme/inbox/` などへ置きます。写真アプリへの登録は不要です。
3. 「声・行動を記録」から本文・日時・状況を保存します。
4. 詳細画面で添付を選んで保存します。撮影日時が不明なら空欄にできます。
5. 前後の出来事やメメの反応は同じメモにまとめます。書き足す場合は「編集する」から更新します。予想は任意で複数選べます。

対応する取り込み形式は、HEVC/H.264のMOV・MP4、JPEG・PNG、M4A・MP3・WAVです。HEICとProResは初版では受け付けません。HEVCの再生はブラウザ・端末に依存し、再生できない場合は原本をダウンロードできます。実際のiPhoneのMOV（約279MB）は保存とChromeでの映像読み込みを確認済みです。HDRの色・音声・全編の目視再生は未確認です。MOVの拡張子は変更せず、そのまま選択してください。

空のDBへ明示した架空のサンプルを追加するには次を実行します。既存記録がある場合は追加しません。

```sh
docker compose exec web python -m app.demo
```

サンプルには「サンプル」と表示します。体重等はメメの実測値ではありません。実データ利用前に画面から削除できます。

## 保存と設定

- コード：`~/personal/app/project-meme/`（Git管理）
- 取り込み元：`~/Movies/project-meme/inbox/`（アプリからは変更しない）
- アプリの添付：`~/Movies/project-meme/media/`（Dockerへ接続）
- 一時ファイル：`media/staging/`
- PostgreSQL：Dockerの`project-meme_postgres`ボリューム

アプリはファイルをコピーします。取り込み元・バックアップは別に容量を使います。非公開リポジトリでも実動画・写真・DBをGitHubへ上げません。

`.env`で次の初期値を変更できます。変更後は`docker compose up -d`で反映します。

| 設定 | 初期値 | 内容 |
|---|---:|---|
| MAX_FILE_BYTES | 1000000000 | 添付1件の上限（1GB） |
| MAX_TOTAL_BYTES | 30000000000 | 保存・予約・削除待ちの合計（30GB） |
| RETENTION_DAYS | 60 | 新規添付の保存期間 |
| PORT | 8000 | localhostのポート |
| MEDIA_DIR | セットアップ時に設定 | 添付の保存先 |

一つの記録の添付は10件まで。53日目（期限の7日前）から案内し、期限を過ぎた添付は非表示にして削除します。「残す」は期限対象外ですが容量には含まれます。起動時と約60秒ごとに期限と失敗を確認し、停止中の処理は次回起動後に行います。本文は残ります。削除失敗は管理画面へ表示し、再試行します。

`MEDIA_DIR`の変更だけでは既存ファイルは移動しません。保存先変更時はアプリを止めてデータも移してください。iPhoneの原本を整理する前に保存・再生・必要なバックアップを確認してください。

## バックアップと復元

MacBook内の別フォルダへ手動保存する初期方式です。本体故障に備える外部保存先と保持期間は未決定です。自動で古いバックアップを消しません。

```sh
python3 scripts/backup.py backup
```

アプリを一時停止し、DBダンプとメディアを `~/Library/Application Support/project-meme/backups/日時/` へ保存します。元々起動していたアプリは終了後に再開します。体調CSVやGitHubはバックアップの代わりになりません。

復元は既存環境を上書きせず、新しいDockerプロジェクトへ行います。

```sh
python3 scripts/backup.py restore '/バックアップの絶対パス' \
  --project meme-restore-check \
  --destination "$HOME/Movies/project-meme/restore-check"
```

復元先は [http://localhost:8002](http://localhost:8002)。同名の環境・保存先がある場合は拒否します。復元先の`restore.env`にも秘密値があるのでGitへ入れないでください。容量には復元先のDB・メディア分も必要です。

## セキュリティと利用範囲

初版はMacBookのlocalhost限定・ログインなしです。同じMacBookの利用者やローカルプロセスからデータを隔離しません。iPhoneからLAN経由で直接使う前に認証・認可・セッション保護を追加します。ポートの公開範囲を勝手に広げないでください。

Host/Origin検証、署名Cookieと照合するCSRFトークン、入力検証、パラメータ化SQL、HTMLエスケープ、CSP、受信容量・時間制限、ファイル内容検証を実装しています。添付は生成名で保存し、アプリ経由で配信します。DB接続権限は通常操作とマイグレーションで分けています。

2026-10-02指定の共通セキュリティ方針を適用し、[Webアプリケーションセキュリティ入門](https://bogus.jp/webapp_security_review.pdf)は参考資料として扱います。教材の固定バージョンや認証実装をそのままコピーする方針ではありません。検査の成功を安全の保証とは扱いません。

## 検証

テスト専用の別PostgreSQLと一時メディアを使用します。`.env`や個人のメディアを読み込まず、通常の記録は変更しません。次のコマンドが最新コードをビルドし、毎回固有の環境でテストして、成功・失敗にかかわらずテスト用DBを片付けます。Pythonは標準ライブラリだけを使い、追加インストールは不要です。PRとmainへのpush時も同じコマンドがGitHub Actionsで動きます。

```sh
python3 scripts/test.py
```

確認済み：記録の保存・編集・再送、辞書と合図、反応の後日追記、体調CSVと数式注入対策、CSRF/Origin/Hostの拒否、容量・パス・偽装ファイルの拒否、期限と「残す」、削除失敗の再試行、予約失効、全データ出力・全削除、生成HEVCの取り込みと部分配信。テスト結果と手動検証の詳細は開発説明を参照してください。

未確認：実際のiPhone動画の4K・120fps/HDR再生と向き、iPhone/iPad実機操作、長期間の運用、1GB上限付近の実ファイル。容量は実ファイルと空き容量を確認して調整します。

AI・pgvector、動画変換、ブラウザ内撮影、LANログインは後続です。クラウド・外部AIへデータを送信しません。

撮影日時はMOV/MP4の埋め込み情報から保存時に自動取得します。手入力があればそちらを優先し、情報がない・不正な場合は「不明」のまま保存します。保存後は添付の「撮影日時を修正」から変更できます。日時入力は日付・時・分を分け、日本時間の24時間表示と「今の日時」ボタンを用意しています。本文の出来事の日時は別に管理します。


声・行動の文章入力はメモ一つです。伝えたかったことの予想は別に複数選べ、予想ごとに「合っていそう・合わなそう・まだ分からない」を選べます。場所は「家のどこ？」から選択できます。


「保存管理 → アプリの写真とアイコン」から、ホーム・ヘッダー・ブラウザタブの写真を変更できます。JPEG/PNG（10MBまで）に対応します。HEICはMacのプレビューでJPEGへ書き出してから選択してください。表示用画像は `~/Movies/project-meme/media/profile.jpg` に保存し、GitHubには含めません。添付の期限削除とは別に保持し、写真を外す操作または全記録削除で削除します。全データ出力・バックアップには含まれます。


観察の文章入力は「そのときの様子・前後のメモ」一つにまとめています。前後の出来事、自分がしたこと、メメの反応を続けて書けます。あとから書き足す場合も「編集する」で同じメモを更新します。記入例は入力欄の外に表示し、記録としては保存しません。以前の別欄の補足は読み取り用に残しています。

添付の送信が切れた場合は、同じファイルで「保存」を再試行できます。処理済みなら重複保存せず、失敗した予約は新しい予約でやり直します。送信中のファイル・撮影日時の選び直しはできません。途中でアプリが停止した場合、再送はファイルの先頭から行います。
