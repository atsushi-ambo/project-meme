# MacBookのCodexに渡す指示

このリポジトリをMacBookにcloneし、Codexで開いて以下を依頼する。

> README.mdとdocs/design.mdを読んで、「めめのノート」のローカル試作を実装してください。まずリポジトリのAGENTS.md等の指示を確認してください。iPhoneのChromeを主対象としたブラウザアプリです。PythonとFastAPI、Jinja2テンプレート、HTML/CSSを使い、アップロードなどには必要な少量のJavaScriptを使ってください。ホーム、声・行動の記録、体調日記、めめ辞書、保存管理の画面を作ってください。日本語UIで、大きな操作ボタン、読みやすい文字、温かく落ち着いた配色にしてください。めめの写真は未提供なので、差し替え可能なプレースホルダーにしてください。
>
> この段階はサンプルデータとSQLiteによるローカル保存の試作です。ローカル保存の制約を画面に表示し、クラウド保存済みと表示しないでください。個人の実データを外部に送信しないでください。データアクセスを分離し、後から認証・DB・非公開オブジェクト保存を接続できる構成にしてください。まず添付なしの記録・編集・削除・辞書への関連づけ・体調履歴・CSVと印刷用表示を動かしてください。メディアはiPhoneのカメラで撮った動画・写真のファイル取り込みを実装してください。ブラウザ内の録音・撮影は初版に含めません。Python学習が目的なので、Pythonの処理が追える構成と説明にしてください。自宅のMacBookで動かすSQLiteとメディアフォルダを基本にしてください。
>
> 猫語の翻訳や診断、未検証の確率を作らないでください。めめ辞書の候補はユーザーの仮説であると分かる表示にしてください。60日保存はまだサーバーの期限削除が動かない段階なら、設定のプレビューとして明示してください。
>
> 実装後はPythonの構文・起動確認と主要な記録操作を確認してください。自動テストは入力の保存、日時・期限計算、CSVのエスケープなど壊れると困る処理に絞ってください。実機未確認の機能を動作確認済みと報告しないでください。起動方法、確認したこと、未実装のことをREADMEに追記してください。

## 次の段階の依頼

試作後は自宅LANでの利用を整える。ログインとセッション保護、アップロードのサイズ・形式制限、安全な保存パス、容量上限、期限処理、バックアップを実装する。外部ポートを公開せず、MacBook起動中だけ利用できる条件をREADMEに記す。動画の保存先やDBをGitに含めない。認証情報は環境変数で管理し、サンプル設定に秘密値を入れない。MacBook停止中の期限処理は次回起動時に行う。

将来クラウド移行を希望した場合に、保存先・費用・認証方式を改めて選定する。
