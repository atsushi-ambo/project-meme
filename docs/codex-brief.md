# プロジェクト・メメ：Codex向け開発指示

`README.md`と`docs/design.md`、適用されるAGENTS.md等を読んで実装する。アプリ名とプロジェクト名は「プロジェクト・メメ」、リポジトリは`project-meme`、仮説集は「メメ辞書」。

## 実装の目的

動画・鳴き声と前後の状況を記録し、観察 → 仮説 → 働きかけ → 反応 → 振り返りの流れを動かす。体調も記録する。観察した事実と飼い主の解釈を分け、支持する例、不一致、未判断を保存できるようにする。猫語の翻訳、診断、意図の確定、未検証の確率を作らない。

## 環境と構成

Python、FastAPI、Pydantic、Jinja2、HTML/CSS、少量のJavaScript、PostgreSQL、SQLAlchemy、Alembicを使う。Docker ComposeでアプリとDBを起動し、PythonとPostgreSQLをMacBookへ直接インストールしない。DB・メディアは永続保存しGit管理外とする。具体的なバージョンと設定は現行の公式資料で確認する。

まずMacBookのlocalhostだけで利用し、DBポートは外部公開しない。iPhoneで撮ったファイルをAirDrop等でMacBookへ移して取り込む。ブラウザ内の録音・撮影は初版に含めない。LANからの直接利用は認証・セッション保護を整えた次の段階で追加する。

## 作る機能

ホーム、観察記録と一覧・詳細、メメ辞書、体調日記、設定・保存管理。日本語で読みやすく、大きな操作ボタンを設ける。メメの写真は差し替え可能なプレースホルダー。

添付なしの保存・編集・削除から実装する。観察への追記、仮説の関連づけ、働きかけと反応、日付・タグ・文字による検索、体調履歴、CSVと印刷用表示を動かす。その後、写真・動画・音声の取り込みを加える。許可形式と容量上限を明示し、ファイルの内容・サイズ・パスを検証する。

時刻はUTC保存、日本時間表示。撮影・出来事・登録日時を区別する。不明な値は空欄とし、未入力を正常やゼロにしない。保存失敗を成功と表示せず、可能な範囲で入力を保持する。

60日保存は期限処理を実装・検証するまでは設定プレビューと表示する。実装する場合は53日案内、60日期限、「残す」、停止中の未処理分を起動時に処理する動作、失敗の再試行を確認する。本文は期限後も保存する。容量不足では添付を止め、記録の文章は続けられるようにする。

## 安全性と学習用説明

共通セキュリティ方針を適用し、サーバー側の入力検証、パラメータ化SQL、HTMLエスケープ、CSRF対策を行う。メディアは静的公開フォルダ外に保存する。実データを外部AIへ送信しない。秘密やDB、メディアをコミットしない。

Pythonの処理を追える構成にする。HTTPルート、入力モデル、保存処理、期限・CSV、テンプレートを分ける。ER図と具体例で主キー・外部キー・多対多・制約・トランザクションを説明し、Pythonの処理に対応するSQLも示す。画面を先に実装し、JSON APIは共通の保存処理と認証・入力規則で後から追加できるようにする。

pgvectorは後続。初版では意味検索やAI接続を必須にしない。

## 検証と報告

構文、Docker起動、マイグレーション、主要操作を確認する。自動テストは保存、整合性、入力拒否、日時・期限、CSVの引用と数式注入対策、添付の安全性などに絞る。正当な操作の成功と不正な操作の拒否を対で確認する。

iPhone由来のHEIC・HEVC・向き・再生を実機未確認なら動作確認済みと報告しない。READMEへ起動方法、処理の説明、検証結果、未実装事項、データ保存・バックアップの条件を追記する。
